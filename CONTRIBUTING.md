# Mitarbeit / Contributing

OWPanel ist in früher Entwicklung und darf von jedem getestet und genutzt werden. Fehler und Wünsche trägst du bitte als Issue ein. Größere Pull Requests bitte vorher in einem Issue abstimmen.

OWPanel is in early development, and anyone may test and use it. Please report bugs and wishes as an issue. Please discuss larger pull requests in an issue first.

## Lizenz / License

Beiträge stehen unter derselben Lizenz wie das Projekt: AGPL-3.0-or-later.

Contributions are licensed under the same license as the project: AGPL-3.0-or-later.

## Regeln / Rules

- Prüfe neue Funktionen gegen die Abgrenzung in [docs/KONZEPT.md](docs/KONZEPT.md).
- Halte die Regeln in [docs/SICHERHEIT.md](docs/SICHERHEIT.md) ein.
- Sichtbare Texte gehören in die Sprachdateien für `de` und `en`.
- Code, Bezeichner und Commit-Nachrichten sind auf Englisch.
- Serverskripte müssen wiederholbar sein und ShellCheck bestehen.
- Teste Serverskripte nur auf Wegwerf-VMs.
- Checke keine Geheimnisse ein, also keine `.env`-Dateien, Schlüssel oder Tokens.

Sicherheitslücken bitte nicht als öffentliches Issue melden, siehe [SECURITY.md](SECURITY.md).

Please do not report security issues in public. See [SECURITY.md](SECURITY.md).

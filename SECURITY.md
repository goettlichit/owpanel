# Sicherheit / Security

OWPanel ist in früher Entwicklung. Bis zum ersten öffentlichen Release gibt es keine unterstützte Version; Meldungen zum aktuellen Stand von `main` sind trotzdem willkommen.

OWPanel is in early development. Until the first public release there is no supported version; reports about the current state of `main` are welcome all the same.

## Lücken melden / Reporting a vulnerability

Bitte melde Sicherheitslücken nicht in öffentlichen Issues, sondern über die private Meldefunktion von GitHub (Tab **Security**, **Report a vulnerability**).

Please do not open public issues for vulnerabilities. Use GitHub's private reporting instead (**Security** tab, **Report a vulnerability**).

Bitte nenne betroffene Version, Schritte zum Nachstellen und mögliche Auswirkungen.

Please include the affected version, steps to reproduce, and the possible impact.
